GPS AND MOTION PERMISSIONS

Downloaded content:// pages may block sensors. Serve this file on your phone using localhost. Install Termux, then run:

pkg install python
termux-setup-storage
cd ~/storage/downloads
python -m http.server 8080 --bind 127.0.0.1

Open Trip Deck on localhost in Chrome. Allow precise location in Android app permissions and Chrome site settings. Keep screen on and browser visible during trips.

Demo motion is simulated. Live attitude is approximate and requires a fixed mount and calibration. Export trips regularly; browser storage is limited.
