TripDeck V0.6 — experimental Android vehicle dashboard.
Build via GitHub Actions. Geographic assets are downloaded and simplified during compilation, then packaged locally in the APK. Sources: Natural Earth (public domain), US Census 2024 cartographic boundaries, Statistics Canada 2021 census boundaries (Open Government Licence – Canada). No online map service required at runtime. Online place-name lookup remains optional and separate. Reset clocks clears current trip including breadcrumbs; export or archive first. Calibrate while parked with phone mounted. Vehicle mode attenuates displayed angles; not a safety instrument. Debug APKs built on different runners may have different signing keys; export existing trips before uninstalling if Android refuses the update.
